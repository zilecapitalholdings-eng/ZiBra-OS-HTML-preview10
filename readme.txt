ZiBra OS — HTML Preview Package

CONTENTS
- index.html: Main landing page
- style.css: Responsive design and visual styling
- script.js: Mobile navigation and footer year
- assets/: Reserved for images and other static assets

HOW TO PREVIEW
1. Extract the ZIP file on your computer.
2. Open the extracted folder.
3. Double-click index.html to open it in your browser.
4. An internet connection is needed for the optional Google Fonts import. The page itself works without it.

HOW TO PUBLISH WITH NETLIFY DROP
1. Open https://app.netlify.com/drop
2. Sign in or create a Netlify account if prompted.
3. Drag the extracted zibra-os-preview folder onto the Netlify Drop area.
4. Wait for Netlify to publish and provide a preview URL.

IMPORTANT
This is a standalone marketing-preview website. It is separate from the existing ZiBra OS application.
It does not connect to Supabase, GitHub, or the live ZiBra OS deployment, and it does not change any existing project.
Dashboard figures are illustrative design content, not live business data.
AI Scout is clearly marked as in development. Other feature details should be checked against the current product before public launch.
Update the contact email in index.html before publishing if hello@zibraos.com is not your intended address.
